About the data & counting rules Steam Feature Atlas © 2026 Peter Thoman

Feature Score: Steam Cloud +3; Steam Achievements +2; In-App Purchases −1; Gamepad Recommended, Includes Source SDK and VR Only 0; other features +1. Feature Count includes zero- and negative-point badges. The maximum score sums positive weights.

Counting toggles change columns, counts and scores; active filters still apply. Tags do not affect scores or counts. All requirements and exclusions apply together. Games with unknown feature or tag data cannot satisfy filters for that data. Set Minimum reviews to 0 to include unknown review counts. Excluding Early Access also excludes unknown Early Access status.

Review Score: the percentage of positive reviews. Steam review counts cover Steam purchases in all languages; older counts may use different rules.

Badges are publisher claims and may be incomplete or inaccurate. Missing Steam Cloud does not rule out another cloud-save service.

About & FAQ

This is a just-for-fun project to allow quick browsing of the Steam catalog with a focus on features and tags.

It is not and will never be commercial in any way, and all the data/navigation/filtering happens locally in your browser.

FAQ

Why?

Two reasons:

  • I've wanted something like this for almost a decade; SteamDB is close, but with a different focus. Now, if I e.g. want to see all metroidvanias that have local campaign co-op, sorted by review score, I can just do it.
  • I like several Steam features quite a lot, and I feel like Valve doesn't do enough to incentivize developers/publishers to implement them. Maybe a "Feature Score" adds a bit of an incentive.

How?

This takes data from various sources—but primarily Steam itself—and builds a compressed bundle that is loaded directly into your browser. All the processing for filters etc. happens there. The data is updated once a day, but not for the whole catalog, so individual games' data can be older.

Why does game X show / not show feature Y, even though it clearly has / doesn't have that?

Take it up with the developer / publisher or Steam. No, really, please do. I think there should be much stricter enforcement / control of these things, but currently actually keeping this correct is mostly on the publisher.

What's the "Hall of Shame"?

It's a list of games that are super popular but don't feature Steam Cloud saves (or don't correctly tag themselves as featuring them). It excludes games that don't have the Single-player feature, and MMOs, since both can have good reasons not to feature cloud saves.

Is this slop?

This was mostly built via LLM, yes. I did use roughly 2 decades of engineering experience to make sure it's not doing anything tremendously stupid, and iterated on the visuals, layout and user-facing text until it wasn't too offensive to my tastes, but your mileage may vary.
